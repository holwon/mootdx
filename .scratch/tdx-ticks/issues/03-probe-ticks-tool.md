# 03: 验收现有健康检查工具 `probe_ticks`

**What to build:**

`mootdx/tools/probe_ticks.py` **已经存在于本仓**（先前随一手校准一起落地）。本票不是「新增」，而是：

1. 确认它在 `ticks` 方法落地后仍然可用
2. 决定是否需要把它从「直调 `StdQuotes`」改为「经 `serve` 协议验证」

这个决定留到施工阶段——如果 `ticks` 方法与 `StdQuotes.transactions` 的字段集完全一致（按 spec 应当如此），则工具无需改动；如果未来 `ticks` 增加了清洗或换算（本批明确不做），工具就得跟着改。

**判据是成交量，不是行数，也不是成交额**：

- **行数**无法自证完整性——只有事先知道应有行数时才可用。
- **成交额**天然对不上：分笔的 `price` 是 3 秒快照内最后一笔的价、`vol` 是快照内合计，`price × vol` 与真实成交额必然有差（实测单日最高 0.109%）。故额差只提示、不判失败。
